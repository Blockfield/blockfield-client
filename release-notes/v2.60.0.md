# Blockfield/blockfield-releases v2.60.0

## Кратко

Клиент для сервера 2.61.0: невидимая коллизия под нарисованным декором (blockfield-decor 1.1.0), меню режимов
под новый режим AWP (мод 1.39.0) и новые стинги захвата и потери точки (music-v4). Обновление обязательно: сервер 2.61.0 работает в паре с этим клиентом.

## Для игроков

- На картах с клипами (Dust2, Mirage, Overpass, Ancient, Nuke) игрок стоит на брезенте, бордюрах и плитах, а не
  проваливается в них. Пули сквозь эти невидимые слои пролетают.
- Меню «Без рейтинга» вмещает больше режимов: карточки переносятся рядами (5 режимов — 3 + 2), названия и
  подсказки видны целиком, у AWP своя иконка прицела.
- Новые короткие стинги при захвате и потере точки.
- Новые карты Codre (Cache, Sandstorm, Hamburg) и режим AWP на карте AWP_ICE приходят с сервером 2.61.0.

## Технические изменения

- `mods/blockfield-decor.pw.toml`: blockfield-decor 1.1.0 с блоком `blockfield:clip_layer` (layers 1..15,
  коллизия n/16, невидимый, снаряды проходят).
- `config/tacz-common.toml`: `PassThroughBlocks += "blockfield:clip_layer"`, чтобы пули TaCZ проходили сквозь клипы.
- `mods/blockfield-client.pw.toml`: мод 1.39.0 — `MenuLayout` не сжимает карточки уже их текста, неполный ряд
  по центру.
- `mods/blockfield-music.pw.toml`: music-v4 из R2, новые `sting_captured` и `sting_lost`.

## Обновлённые компоненты

- Blockfield Decor v1.1.0: обновление v1.0.1 → v1.1.0.
- blockfield-client v1.39.0: обновление v1.38.2 → v1.39.0.
- blockfield-music v4: обновление music-v3 → music-v4.

## Совместимость и необходимые действия

Парный выпуск с сервером 2.61.0: decor — общий мод (side=both), новый блок должен быть на обеих сторонах. Лаунчер
обновит пак сам. Вайп не нужен.
