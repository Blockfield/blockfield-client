# Blockfield/blockfield-releases v2.57.0

## Кратко

Клиентская сборка 2.57.0: блоки оформления карт переехали из мода Blockfield
в отдельный мод blockfield-decor 1.0.1 (side both, те же id `blockfield:*`),
сам мод обновлён до 1.34.0. Совместима с сервером 2.58.0, который выходит
первым и поддерживает оба клиента — 2.56.0 и 2.57.0.
