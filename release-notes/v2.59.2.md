# Blockfield/blockfield-releases v2.59.2

## Кратко

Клиентская сборка 2.59.2 выпускается парой с сервером 2.60.2: мод blockfield
обновлён до 1.36.0, а Superb Warfare уже закреплён на bf21 с прошлого выпуска
ветки main. Для игроков меняются два поведения: рычаги на картах больше нельзя
переключить и удар прикладом по технике засчитывается только с честной
дистанции. После переключения пары клиенты 2.59.1 не входят, пока не обновятся.

## Для игроков

Изменения поведения:

- Рычаги на картах (мод 1.36.0) больше нельзя переключить: ни рукой, ни клавишей
  взаимодействия TACZ. Подсказка «[E]» у рычагов больше не показывается.
- Удар прикладом SBW по технике засчитывается только с честной дистанции
  (SuperbWarfare bf21, исправление против поддельных пакетов). Честный удар
  работает как раньше: в упор и до ~3 блоков до корпуса, с любой стороны
  техники. Удар по быстро едущей технике может не засчитаться.

Исправления, новое: нет.

## Технические изменения

- `mods/blockfield-client.pw.toml`: blockfield-client 1.35.0 → 1.36.0 (jar из
  релиза Blockfield/blockfield-mod v1.36.0, sha1 сверен со скачанным файлом);
  `index.toml` и хеш в `pack.toml` обновлены.
- `mods/superbwarfare.pw.toml`: без изменений в этом выпуске — bf21 уже
  закреплён на main (PR #28, merge 89a84c4).
- `pack.toml`: 2.59.1 → 2.59.2.
- `release-notes/` в `.packwizignore`: каталог описаний не индексируется в
  раздачу и не уходит игрокам.
- Базовый образ раздачи закреплён по digest (#29):
  `nginx:1.28-alpine@sha256:a8b39b...` — тот же digest, из которого собран
  v2.59.1, пересборка меняет образ только через ревью PR.
- Деплой раздачи — через webhooks Dokploy с проверкой результата и откатом
  (#21–#26): успех только после завершения обновления swarm, раздельные
  лимиты, окно монитора читается как JSON, при ошибке docker печатается
  ответ registry.

## Обновлённые компоненты

- blockfield-client: обновление v1.35.0 → v1.36.0.
  - v1.36.0 — Кратко: игроки без права строить больше не переключают рычаги
    на картах: ни рукой, ни клавишей взаимодействия TACZ. Запрет работает на
    сервере и на клиенте, как у люков и рамок.
  - v1.36.0 — Для игроков: рычаги на картах (матчи, хаб, полигон) нельзя
    переключить: ни правой кнопкой, ни с оружием в руках, ни клавишей E.
    Подсказка «[E]» у рычагов больше не показывается. Исправлений и новинок
    нет.
- Superb Warfare (Blockfield Fabric port): обновление bf20 → bf21 (пин уже на
  main, в этот релиз входит без изменений пина).
  - bf21 — Кратко: сервер засчитывает удар прикладом по технике только с той
    же дистанции, с которой бьёт честный клиент.
  - bf21 — Для игроков: удар прикладом по технике больше не засчитывается
    дальше дистанции удара оружия. Остальное: сведений нет.
