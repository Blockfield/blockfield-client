# Blockfield/blockfield-releases v2.59.1

## Кратко

Клиентская сборка 2.59.1: обновлённые ParCool, Superb Warfare и Create с
серверными проверками сетевых пакетов и исправлением столкновений рельс Create.
Версия 2.59.0 не публиковалась, поэтому изменения описаны от 2.58.0. Для игроков меняется
только честность попаданий и поведение механизмов; пули TACZ летят как раньше.

## Для игроков

Исправления:

- Приклад засчитывается только по целям в досягаемости оружия.
- Огонь техники с тактической карты — только из техники, в которой сидит стрелок.
- Кумулятивная мина бьёт только цель рядом в прицеле и тратится только при попадании.
- Смена скина техники — только рядом (закрытая — только с ключом).
- Действия паркура других игроков отображаются корректно.
- Механизмы на contraption больше не ломаются о невидимые полотна кривых рельс.

Без изменений: простреливаемость путей пулями TACZ, стрельба из своей техники,
удары в упор, смена скина своей техники рядом.

## Технические изменения

- `mods/parcool.pw.toml`: bf6 → bf7 (игнор client-supplied player UUID; continue в рассылке действий).
- `mods/superbwarfare.pw.toml`: bf19 → bf20 (дистанция melee; удалён LaserShootMessage; проверки vehicle fire/lunge mine/skin).
- `mods/create.pw.toml`: bf3 → bf4 (fake-track entity-only collision; wide-треки в тегах; loot_table путь 1.21).
- `pack.toml`: 2.58.0 → 2.59.1 (2.59.0 не публиковалась); `index.toml` хеши обновлены.
- Проверки: 11 клиентских тестов OK (rollback HTTP, deploy gate).

## Обновлённые компоненты

- ParCool (Blockfield Fabric port): обновление bf6 → bf7.
  - bf7: сервер не доверяет идентификатору игрока из сетевых пакетов (закрыта
    подмена чужой выносливости и действий); исправлена потеря действий в общей
    рассылке — паркур других игроков отображается корректно.
- Superb Warfare (Blockfield Fabric port): обновление bf19 → bf20.
  - bf20: сервер проверяет пакеты ближнего боя (дистанция удара), огня техники
    (только из занятой техники), кумулятивной мины (цель рядом, расход при
    попадании) и смены скина (техника рядом, закрытая — с ключом); удалён
    неиспользуемый пакет лазерного выстрела.
- Create (Blockfield Fabric port): обновление bf3 → bf4.
  - bf4: невидимые полотна кривых рельс сталкиваются только с сущностями
    (чинятся механизмы contraption и вентиляторы); широкие пути добавлены в теги
    путей и дают дроп; путь таблицы добычи приведён к 1.21.

## Совместимость и необходимые действия

- Работает с сервером 2.60.1 (те же пины side=both); контракт проверяется gate деплоя.
  Выкатка парой: сначала сервер, затем клиент; после обновления сервера клиенты
  2.58.0 и старше не подключатся — обновитесь через лаунчер.
- Обновление — через Blockfield Launcher или вручную из архивов релиза.
