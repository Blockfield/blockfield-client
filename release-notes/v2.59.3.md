# Blockfield/blockfield-releases v2.59.3

## Кратко

Клиентская сборка 2.59.3 выпускается парой с сервером 2.60.3: мод blockfield
обновлён до 1.37.0. Для игроков меняются два поведения: миникарта и баланс БК
больше не закрывают экран отладки F3, а статичные дисплеи карт выведены из
клиентского тика — заметно выше FPS на Overpass и Mirage при том же виде карт.

## Для игроков

Изменения поведения:

- Миникарта и баланс БК под ней не рисуются, пока открыт экран F3: они
  закрывали его левую колонку (мод 1.37.0).
- Статичные дисплеи карт (декор из тысяч display-сущностей) больше не тикают
  на клиенте: вид карт тот же, FPS выше — сильнее всего на Overpass, слабее
  на Mirage (мод 1.37.0).

Исправления, новое: нет.

## Технические изменения

- `mods/blockfield-client.pw.toml`: blockfield-client 1.36.0 → 1.37.0 (jar из
  релиза Blockfield/blockfield-mod v1.37.0, sha1 сверен со скачанным файлом);
  `index.toml` и хеш в `pack.toml` обновлены.
- `pack.toml`: 2.59.2 → 2.59.3.
- Клиентская часть StaticDisplays (мод 1.37.0): запечённое дерево дисплеев
  вынуто из lookup, секций и списка тика `ClientLevel`; пакет к такой сущности
  сначала возвращает его (`DisplayDetachMixin`); `/bfdisplays off`, шейдеры и
  смена мира возвращают всё.
- `MinimapHud` (мод 1.37.0): не рисуется при `showDebugScreen()`.

## Обновлённые компоненты

- blockfield-client: обновление v1.36.0 → v1.37.0.
  - v1.37.0 — Кратко: приёмы паркура (ParCool) теперь задаются из админки
    сайта и применяются сразу, без рестарта сервера; в командном бою (TDM)
    больше нет защиты баз; миникарта не закрывает экран отладки F3;
    подготовка раунда и телепорт на спавн стали тихими; статичные дисплеи карт
    больше не нагружают тик сервера и кадр клиента.
  - v1.37.0 — Для игроков (клиентская часть): миникарта и баланс БК под ней
    не рисуются, пока открыт экран F3; декор карт из тысяч display-сущностей
    больше не тикает и не отслеживается каждый тик, вид карт тот же.
    Серверные изменения мода 1.37.0 (TDM без защиты баз, тихая подготовка и
    телепорт, ParCool из админки) описаны в релизе сервера 2.60.3, здесь не
    повторяются.

## Совместимость и необходимые действия

- Выпускается парой с server 2.60.3. Выкатка парой: сначала сервер, затем
  клиент; gate деплоя проверяет совместимость с работающим сервером.
- После переключения пары клиенты 2.59.2 не входят, пока не обновятся — обновитесь
  через Blockfield Launcher или вручную из архивов релиза.
- Вайп не требуется; перезаход нужен.
